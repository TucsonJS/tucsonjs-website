# Font Awesome Configuration

Detected by the Font Awesome agent tools. Commit this file so the whole team benefits.

## Integration

- **Method:** Kit embed (SVG+JS) — `<script>` tag in `src/layouts/Layout.astro`
- **License:** Pro
- **Kit ID:** `9f1d29da48` (public kit code embedded in the script URL; not a secret — see note below)
- **Families:** duotone (only family currently used; kit is a "By Icon" subset kit, not the full Pro library)

## Defaults

- **Style:** duotone
- **Family:** duotone

## Import Pattern

- No npm packages installed — the Kit's hosted JS (`https://kit.fontawesome.com/9f1d29da48.js`) auto-replaces `<i class="fa-duotone fa-{icon-name}">` tags with inline SVG at runtime.
- Markup: `<i class="fa-duotone fa-{icon-name}"></i>`

## Conventions

- Icon color/size are controlled via plain CSS targeting the rendered element (e.g. `.detail i { color: ...; font-size: 1.25rem; }`), since the Kit script preserves the original classes when it swaps `<i>` for `<svg>`.
- This is a scoped "By Icon" Kit — before using a new icon, add it to the Kit at fontawesome.com/kits first, or it won't render.
- Icons currently in the Kit: `sun-bright`, `moon-stars`, `map-location-dot`, `calendar-clock` (all Duotone).

## Security note

The Kit ID above is the same code that appears in the public `<script src="https://kit.fontawesome.com/9f1d29da48.js">` tag already shipped to every visitor — it is meant to be public and is safe to commit. It is **not** the Font Awesome account API token (used for `fa login` / `FA_API_TOKEN`), which grants account-level access and must never be committed or placed in client-side code.
